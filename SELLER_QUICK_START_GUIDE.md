# Seller Workspace Enhancements - Quick Start Guide

## What's New

Your seller workspace now includes powerful enterprise features for managing products, orders, team members, and compliance.

## 🎯 Bulk Actions

### Catalog Bulk Actions
**Access**: Catalog screen → Long-press any product

**Features**:
- ✅ Change status for multiple products at once
- ✅ Adjust prices by percentage (-50% to +50%)
- ✅ Reassign categories
- ✅ Delete multiple products

**Steps**:
1. Long-press a product to enter selection mode
2. Tap checkboxes to select multiple products
3. Tap the "Bulk Actions" icon (checklist) in the app bar
4. Choose your action and configure settings
5. Confirm and watch the progress

### Orders Bulk Actions
**Access**: Orders screen → Long-press any order

**Features**:
- ✅ Update status for multiple orders
- ✅ Export orders to CSV
- ✅ Batch fulfillment workflows

**Steps**:
1. Long-press an order to enter selection mode
2. Select multiple orders
3. Tap "Bulk Actions" icon
4. Choose status update or export
5. Apply changes

## 📦 Product Variants & Stock

**Access**: Product detail → "Manage Variants" button

**Features**:
- ✅ Create variants with unique SKUs
- ✅ Set variant-specific prices
- ✅ Track stock per variant
- ✅ Low stock alerts
- ✅ Quick stock updates

**Steps**:
1. Navigate to a product
2. Tap "Manage Variants"
3. Add new variant with SKU
4. Set price and stock levels
5. Configure low-stock threshold
6. Edit anytime by tapping the edit icon

## 📊 Enhanced Analytics

**Access**: Analytics tab in seller hub

**Features**:
- ✅ Time period comparison (Today/Week/Month/Year)
- ✅ Revenue trends with % change
- ✅ Order and customer metrics
- ✅ Revenue per order/customer
- ✅ Color-coded performance indicators

**Metrics**:
- Total Revenue (with change vs. previous period)
- Order Count (with trend)
- Customer Count (with growth)
- Average Order Value (with movement)
- Revenue per Order
- Revenue per Customer

## 👥 Staff Management

**Access**: Settings → Staff Management (Owners only)

**Features**:
- ✅ Invite team members by email
- ✅ Set granular permissions
- ✅ View all staff members
- ✅ Remove staff access

**Permissions**:
- Catalog: Read/Write
- Orders: Read/Write
- Support: Read/Write
- Analytics: Read

**Steps**:
1. Navigate to Staff Management
2. Tap "Invite Staff"
3. Enter email address
4. Select permissions
5. Send invitation (valid 7 days)
6. Staff member receives email and accepts

## 🔐 KYC Compliance

**Access**: Settings → KYC Compliance (Owners only)

**Features**:
- ✅ Submit compliance documents
- ✅ Track verification status
- ✅ Resubmit after rejection
- ✅ View rejection reasons

**Required Documents**:
- Business License/Registration
- Tax Identification Number
- Additional documents (optional)

**Statuses**:
- 🟠 Pending (not submitted)
- 🔵 Under Review (submitted, awaiting admin)
- 🟢 Approved (verified)
- 🔴 Rejected (needs resubmission)

**Steps**:
1. Navigate to KYC Compliance
2. Upload documents to storage
3. Paste document URLs
4. Enter Tax ID
5. Submit for review
6. Wait for admin approval
7. Resubmit if rejected

## 🆘 Support Escalation

**Access**: Support tab → Ticket details

**Features**:
- ✅ Escalate complex issues to admins
- ✅ Provide escalation context
- ✅ Track escalation status

**When to Escalate**:
- Policy violations
- Payment disputes
- Platform-level issues
- Urgent matters requiring admin intervention

**Steps**:
1. Open a support ticket
2. Tap "Escalate to Admin"
3. Provide detailed reason
4. Confirm escalation
5. Admin reviews in moderation queue
6. Receive admin response

## 🎨 UI Features

### Multi-Select Mode
- Long-press any item to activate
- Checkboxes appear for selection
- Actions menu becomes active
- Exit by clearing all selections

### Progress Indicators
- Real-time progress bars for bulk operations
- Percentage completion display
- Cancel option during processing

### Status Chips
- Color-coded status indicators
- Green = positive/active
- Orange = pending/warning
- Red = error/rejected
- Blue = in progress
- Grey = inactive/closed

### Permission Badges
- Visual indicators for access levels
- Owner badge (primary color)
- Staff badge (secondary color)

## 💡 Tips & Best Practices

### Bulk Operations
- Start with a small test batch
- Review settings before applying
- Watch for error messages
- Use filters to narrow selection

### Variant Management
- Use consistent SKU naming
- Set realistic low-stock thresholds
- Update stock regularly
- Deactivate instead of deleting

### Staff Management
- Grant minimum necessary permissions
- Review staff access periodically
- Remove inactive members
- Document role responsibilities

### KYC Compliance
- Upload high-quality document scans
- Use secure cloud storage
- Keep documents up-to-date
- Respond quickly to rejection feedback

### Support Escalation
- Provide detailed context
- Include relevant order/product IDs
- Explain resolution attempts
- Use escalation judiciously

## 🐛 Troubleshooting

### Bulk actions not working
- Check permissions (write access required)
- Verify items are selected
- Check network connection
- Review error messages

### Can't invite staff
- Verify you're the vendor owner
- Check email format
- Ensure invitation limit not reached
- Check network connection

### KYC documents not uploading
- Verify file format (URLs only)
- Check document accessibility
- Ensure proper permissions
- Try resubmitting

### Escalation not working
- Verify support write permission
- Provide escalation reason
- Check ticket status
- Try again if network issues
